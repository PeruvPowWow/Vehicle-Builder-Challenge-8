# Vehicle-Builder-Challenge-8

## Overview

Vehicle Builder is a command-line application designed to allow users to create and manage different types of vehicles, including cars, trucks, and motorbikes. It provides a range of interactive features, such as starting, accelerating, decelerating, and printing vehicle details. The application includes advanced functionalities like towing for trucks and performing wheelies for motorbikes, making it a versatile tool for vehicle management via the command line.

## Description

This project demonstrates the use of TypeScript and inquirer.js to create an interactive application that runs in the command-line environment. Users are guided through a series of prompts where they can create vehicles, manage them by performing various actions, and print the details of any selected vehicle. The intuitive command-line interface allows for easy management of the different vehicle types, showcasing how TypeScript can add robustness to the development of a JavaScript-based CLI.

### Key Features

- Create & Manage Vehicles: Users can create cars, trucks, or motorbikes.
- Advanced Actions: Trucks can tow, and motorbikes can perform wheelies.
- Interactive CLI: Guides users through a series of prompts to manage the vehicles.
- TypeScript Integration: Enhances the application with strong typing for more reliable code.

## Changes Made

- Implemented CLI-based vehicle management using inquirer.js.
- Added vehicle-specific actions (e.g., towing for trucks, wheelies for motorbikes).
- Integrated TypeScript for better type safety and code scalability.
